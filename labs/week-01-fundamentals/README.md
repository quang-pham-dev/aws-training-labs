## 🎯 Week 01 Objectives

Week 01 focuses on building an unshakeable foundation for cloud architecture and security:
- Master the global infrastructure footprint: Regions, Availability Zones (AZs), and Edge Locations.
- Understand the **Shared Responsibility Model** across IaaS, PaaS, and Serverless services.
- Secure the AWS root account, enforce Multi-Factor Authentication (MFA), and configure account budgeting guardrails.
- Setup AWS CLI v2 and establish a strict **Least-Privilege** IAM posture.
